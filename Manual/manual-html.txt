1. ESTRUTURA FUNDAMENTAL DE UM DOCUMENTO HTML

   Todo documento HTML começa com a declaração DOCTYPE e as tags raiz.

   Sintaxe básica:
   <!DOCTYPE html>
   <html lang="[codigo_idioma]">
     <head>
       <meta charset="UTF-8">
       <title>[titulo_da_pagina]</title>
     </head>
     <body>
       [conteudo_visivel_da_pagina]
     </body>
   </html>

2. COMENTÁRIOS EM HTML

   <!-- [texto_do_comentario] -->
   Comentários não são exibidos na página.

3. CLASS E ID – IDENTIFICADORES PARA CSS E JAVASCRIPT

   - id: identifica UM elemento de forma ÚNICA na página. Não pode repetir o mesmo id.
   - class: identifica UM ou MAIS elementos. Pode ser reutilizado em vários elementos.
   - Ambos são usados para aplicar estilos CSS e para manipulação com JavaScript.

   Sintaxe:
   <[tag] id="[nome_unico]" class="[nome_da_classe]">[conteudo]</[tag]>
   <[tag] class="[classe1] [classe2]">[conteudo]</[tag]>  (várias classes separadas por espaço)

   Exemplos de uso (apenas sintaxe, sem resultado):
   <div id="cabecalho" class="container principal">...</div>
   <p id="primeiro-paragrafo" class="texto destaque">...</p>
   <span class="icone"></span>
   <button class="botao primario">[clique aqui]</button>

   - No CSS, seleciona-se por #id ou .class:
     #cabecalho { [propriedade: valor;] }
     .botao { [propriedade: valor;] }

   - No JavaScript (exemplo de referência, apenas estrutura):
     document.getElementById("[nome_id]")
     document.getElementsByClassName("[nome_classe]")
     document.querySelector(".[nome_classe]")

4. TAGS DE TÍTULOS E CABEÇALHOS (heading)

   <h1>[titulo_principal]</h1>
   <h2>[subtitulo]</h2>
   <h3>[nivel_3]</h3>
   <h4>[nivel_4]</h4>
   <h5>[nivel_5]</h5>
   <h6>[nivel_6]</h6>
   Importância decrescente de h1 a h6.

5. PARÁGRAFOS E FORMATAÇÃO DE TEXTO

   <p>[paragrafo_de_texto]</p>

   Formatação inline:
   - <strong>[texto_importante]</strong>
   - <em>[texto_enfatizado]</em>
   - <b>[texto_negrito]</b>
   - <i>[texto_itálico]</i>
   - <u>[texto_sublinhado]</u>
   - <mark>[texto_marcado]</mark>
   - <small>[texto_pequeno]</small>
   - <del>[texto_riscado]</del>
   - <ins>[texto_inserido]</ins>
   - <sub>[subscrito]</sub> e <sup>[sobrescrito]</sup>
   - <code>[codigo]</code>
   - <pre>[texto_pre_formatado]</pre>

6. LINKS (âncoras)

   <a href="[url_destino]" target="[_blank|_self]" title="[texto_ajuda]">[texto_do_link]</a>
   Âncora interna: <a href="#[id_do_elemento]">[texto]</a>

7. IMAGENS

   <img src="[caminho_da_imagem]" alt="[texto_alternativo]" width="[largura]" height="[altura]" loading="[lazy|eager]">

8. LISTAS

   Não ordenada:
   <ul>
     <li>[item_1]</li>
     <li>[item_2]</li>
   </ul>

   Ordenada:
   <ol type="[1|A|a|I|i]" start="[valor_inicial]">
     <li>[item_1]</li>
     <li>[item_2]</li>
   </ol>

   Lista de descrição:
   <dl>
     <dt>[termo]</dt>
     <dd>[descrição]</dd>
   </dl>

9. TABELAS

   <table border="[1]" cellpadding="[valor]">
     <caption>[título_da_tabela]</caption>
     <thead><tr><th>[cabeçalho1]</th></tr></thead>
     <tbody><tr><td>[dado]</td></tr></tbody>
     <tfoot><tr><td colspan="[num]">[rodapé]</td></tr></tfoot>
   </table>

10. DIVISÕES E AGRUPAMENTOS

    <div>[bloco_generico]</div>
    <span>[texto_inline_generico]</span>

11. ESTRUTURAS SEMÂNTICAS HTML5

    <header>...</header>
    <nav>...</nav>
    <main>...</main>
    <section>...</section>
    <article>...</article>
    <aside>...</aside>
    <footer>...</footer>
    <figure>
      <img src="[imagem]">
      <figcaption>[legenda]</figcaption>
    </figure>

12. FORMULÁRIOS

    <form action="[url]" method="[get|post]">
      <label for="[id_campo]">[texto]</label>
      <input type="[text|email|password|number|date|checkbox|radio|file|submit]" name="[nome]" id="[id]" placeholder="[dica]" required>

      <textarea name="[mensagem]" rows="[3]" cols="[30]"></textarea>

      <select name="[opcoes]">
        <option value="[valor1]">[opção1]</option>
      </select>

      <button type="[button|submit|reset]">[texto]</button>
    </form>

13. MULTIMÍDIA

    Áudio:
    <audio src="[audio.mp3]" controls></audio>

    Vídeo:
    <video src="[video.mp4]" controls width="[640]" poster="[preview.jpg]"></video>

14. IFRAMES

    <iframe src="[url]" width="[800]" height="[600]" title="[descrição]"></iframe>

15. CANVAS E SVG

    Canvas:
    <canvas id="[meuCanvas]" width="[500]" height="[400]"></canvas>

    SVG:
    <svg width="[100]" height="[100]">
      <circle cx="[50]" cy="[50]" r="[40]" fill="[red]" />
    </svg>

16. LINKS PARA CSS E JAVASCRIPT

    CSS externo:
    <link rel="stylesheet" href="[estilo.css]">

    CSS interno:
    <style>
      [seletor] { [propriedade: valor;] }
    </style>

    JavaScript externo:
    <script src="[script.js]" defer></script>

    JavaScript interno:
    <script>
      [codigo_js]
    </script>

17. META TAGS IMPORTANTES

    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="[descrição]">
    <meta name="author" content="[autor]">
    <meta name="robots" content="[index|noindex]">

18. ACESSIBILIDADE (ARIA)

    <div role="[banner|main|button]" aria-label="[rótulo]" tabindex="0">[conteudo]</div>

19. HTML ENTITIES (caracteres especiais)

    &lt; &gt; &amp; &quot; &copy; &reg; &nbsp;

20. MICRODADOS (SCHEMA.ORG)

    <div itemscope itemtype="https://schema.org/Person">
      <span itemprop="name">[Nome]</span>
    </div>

21. ATRIBUTOS GLOBAIS (funcionam em qualquer tag)

    - id="[unico]"
    - class="[classe1 classe2]"
    - style="[css inline]"
    - title="[tooltip]"
    - lang="[pt-BR]"
    - tabindex="[0|1]"
    - hidden
    - data-*="[valor_customizado]"

22. ESTRUTURA MÍNIMA COMPLETA (modelo)

    <!DOCTYPE html>
    <html lang="pt-BR">
      <head>
        <meta charset="UTF-8">
        <meta name="viewport" content="width=device-width, initial-scale=1.0">
        <title>[Título]</title>
        <link rel="stylesheet" href="[estilos.css]">
      </head>
      <body>
        <header id="[topo]" class="[cabecalho]">...</header>
        <main class="[conteudo-principal]">...</main>
        <footer class="[rodape]">...</footer>
        <script src="[script.js]" defer></script>
      </body>
    </html>
